# Material excluded from the public edition

The following categories remain on the private reference drive and are not
copied, packaged, uploaded, or placed in public Git history.

| Category | Quantity | Release reason |
|---|---:|---|
| PDF library | 15 files | No item currently clears the commercial-redistribution gate. This includes noncommercial licenses, all-rights-reserved works, unclear editions, and works requiring permission. |
| Wes Cecil recordings | 119 files | Public availability was confirmed, but no redistribution license was found. |
| Edge-case Wikimedia media | Variable | Custom grants, GFDL-only, OGL, IGO, incomplete attribution, or hash/license mismatches require individual resolution. |
| XOWA user state | Entire directory | Machine-specific state is unnecessary and may contain history or preferences. |
| Private portal and audit files | Entire directories | They describe or link to private holdings and are not payload material. |

Donations do not cure a license restriction, and charging only for the physical
drive does not make a noncommercial work safe to include. A future permission
grant can move an item into the public edition only after it is documented and
the release gate is updated.
