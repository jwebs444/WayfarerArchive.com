# Contributing

The repository covers the public website, its tests, documentation, and deployment configuration. Archive payloads, drive-builder experiments, release packages, and unrelated research do not belong in Git history.

Before opening a change:

1. Run `pnpm install --frozen-lockfile`.
2. Run `pnpm test`.
3. Keep public-facing text accessible, responsive, and compatible with UTF-8.
4. Keep generated build output and large downloadable artifacts out of Git.
