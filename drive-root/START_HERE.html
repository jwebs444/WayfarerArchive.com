A self-contained English Wikipedia with portable readers, a curated image cache, source records, and integrity checks. No network connection is required after setup.

Windows

Double-click LAUNCH_WIKIPEDIA_WINDOWS.cmd.

Linux

Run LAUNCH_WIKIPEDIA_LINUX.sh.

macOS

Run OPEN_WIKIPEDIA_MACOS.command.

If a launcher is blocked, read README.txt. Licensing, attribution, and source links are in the LEGAL folder. File hashes are in INTEGRITY.
