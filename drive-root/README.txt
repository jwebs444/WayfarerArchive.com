WAYFARER'S ARCHIVE — PUBLIC EDITION

This edition is designed for lawful public redistribution, including copies
provided on physical media for a fee. It contains an offline English Wikipedia,
an open-source reader, portable Java runtimes, and a verified selection of
freely reusable Wikimedia images.

Windows: double-click LAUNCH_WIKIPEDIA_WINDOWS.cmd
Linux: run LAUNCH_WIKIPEDIA_LINUX.sh
macOS: run OPEN_WIKIPEDIA_MACOS.command

Read LEGAL/README.txt and LEGAL/WIKIMEDIA_MEDIA_ATTRIBUTION.csv for licenses,
credits, source links, and important limitations. Wikipedia is informational;
it is not professional medical, legal, or safety advice.

No books or lecture recordings from the private reference archive are included.
