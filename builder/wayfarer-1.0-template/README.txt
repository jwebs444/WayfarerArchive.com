WAYFARER'S ARCHIVE — OFFLINE WIKIPEDIA

Windows
  Double-click LAUNCH_WIKIPEDIA_WINDOWS.cmd.

macOS
  Double-click LAUNCH_WIKIPEDIA_MAC.command. On first use, macOS will open the
  bundled Kiwix disk image and ask you to drag Kiwix to Applications. Run the
  launcher again afterward.

Linux (64-bit Intel/AMD)
  Run LAUNCH_WIKIPEDIA_LINUX.sh. If the drive is mounted with no-execute
  permissions, the launcher copies only the small Kiwix reader to the system
  temporary directory and keeps Wikipedia on this drive.

The Wikipedia archive is self-contained. Internet access is not required.
On Windows and Linux, the bundled reader is configured in portable mode so its
settings stay beside the reader. macOS may store settings in the user's profile.
The encyclopedia itself remains unchanged.

Licensing and source attribution are included with the release notices and the
offline attribution pages linked from retained images.
